  HOW TO EDIT THIS FILE
  ---------------------
  Every text block starts with "## " followed by a key, e.g. "## hero_title".
  DO NOT rename, delete or reorder the keys — the website looks them up by name.
  Only change the text UNDER a key.

  Formatting you can use:
    - A line break in the text becomes a line break on the website.
    - An empty line becomes a paragraph break.
    - **bold**  →  bold
    - *italic*  →  italic
    - [link text](https://example.com)  →  a link

  HTML is not allowed and will be shown as plain text (this is on purpose,
  so a typo can never break the page).
-->
